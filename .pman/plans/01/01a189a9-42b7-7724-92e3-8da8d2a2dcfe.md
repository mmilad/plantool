## Target picture
A familiar, work-oriented UI with clear project navigation, an efficient ticket overview and readable detail views. Jira guides information architecture and workflows; design, language and branding stay independent.

## Order
1. Define UI direction and information architecture.
2. Define a local, consistent icon system.
3. Design ticket navigation, list and filters.
4. Rework ticket detail and editing.
5. Integrate project overview and planning documents.
6. Address responsive layout and accessibility.
7. Review and refine visually across typical data states.

## Icon guideline
Icons give orientation and make actions faster to recognise. Uniform stroke width and sizes; local inline SVGs or an existing icon set if already available. No external assets. Important actions also get text or an accessible name. Ticket kinds, statuses and priorities get distinct, consistent symbols.

## Out of scope
No Jira copy, no Jira assets or trademarks, no data-model changes purely for looks. Agree on concept and priorities before implementation.
