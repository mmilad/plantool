## Goal
The pman web UI is a calm, simple planning workspace with its own identity. Visual direction: fp.dev (plain, focused; provisional and open to change). Jira is a reference for workflows only (navigation, ticket overview, filters, detail views) — no visual copy, trademarks or assets.

## Guardrails
- One consistent, local icon system (inline SVG); no external assets or new runtime dependencies.
- Project boundaries and the security rules of the local server stay in place.
- Agents and people see the same plan: readiness, code plans and design checks are visible next to the tickets.

## Acceptance criteria
- Navigation and work areas are clearly structured on desktop and narrow screens.
- Ticket tree, search/filter and ticket detail form one understandable workflow.
- Goals, plans and decisions are readable, linkable and editable with revision safety.
- The overview names the project and shows a helpful starting point.

The execution order lives in [the UI plan](01a189a9-42b7-7724-92e3-8da8d2a2dcfe); the review process in [the review goal](01a189ac-28ff-73c2-8a77-2320703d3924).
